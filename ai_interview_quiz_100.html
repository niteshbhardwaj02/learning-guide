How to use it

  1. Read the companion guide and explain each answer aloud.
  2. In exam mode, answers stay hidden until you submit. In practice mode, checking an answer reveals feedback and locks that question.
  3. Flag questions, use the question navigator, and return to unanswered items.
  4. Review your topic scores and explanations, then retry mistakes or export your result.

A timer, once started, continues across reloads or when the browser is closed. An expired session is submitted when you return. Untimed mode has no deadline.

No account, API key or installation is needed. Progress is saved only in this browser when storage is available. Private browsing, clearing storage or moving the file may remove it.
