Section 01 / 10

AI and machine learning foundations

Q001FoundationScenario

What does an AI engineer or AI developer actually do?

Answer

Turn a product problem into a reliable, measurable AI system: define success, prepare data, build a baseline, evaluate, integrate, deploy and monitor. AI developers often emphasize application integration; AI engineers may also own training and infrastructure. Titles overlap, so clarify the actual responsibilities.

Practice aloud: Describe the baseline, the production failure you fear most, and how you would detect it.

Technical references: Google: Rules of Machine Learning

Q002FoundationConcept

How do AI, machine learning, deep learning and generative AI differ?

Answer

AI is the broad field of systems performing tasks associated with intelligence. Machine learning learns patterns from data; deep learning uses multilayer neural networks. Generative AI produces content such as text, audio or images. These labels overlap: a transformer-based language model is both deep learning and generative AI.

Practice aloud: Give an example of AI without machine learning and an example of non-generative deep learning.

Q003FoundationConcept

What are supervised, unsupervised, self-supervised and reinforcement learning?

Answer

Supervised learning uses input-target examples. Unsupervised learning seeks structure without task labels. Self-supervised learning constructs targets from the data itself, such as predicting a masked token. Reinforcement learning learns a policy from rewards obtained through interaction, often with delayed consequences.

Practice aloud: Explain why self-supervised pretraining can still be followed by supervised fine-tuning.

Technical references: OpenAI Spinning Up: Reinforcement learning concepts

Q004FoundationConcept

How do regression and classification differ?

Answer

Regression predicts a numeric target such as delivery time. Classification predicts categories, often through class probabilities. Linear regression commonly models a numeric response; logistic regression models class probability through a logistic link despite its name. Choose the target, loss and metric to match the decision.

Technical references: scikit-learn: Logistic regression

Q005IntermediateDiagnosis

What is the bias-variance trade-off?

Answer

Bias is systematic error from restrictive assumptions; variance is sensitivity to the training sample. Too-simple models may underfit, while flexible models may fit noise. Use learning curves, held-out performance and domain understanding to diagnose the problem; high training accuracy alone does not show useful generalization.

Technical references: Google ML Crash Course: Overfitting

Q006FoundationDiagnosis

How do you detect and reduce overfitting?

Answer

Look for a growing training-versus-validation gap on an appropriate split. Consider simpler models, regularization, early stopping, more representative data or valid augmentation. First rule out leakage and distribution mismatch. Select interventions using validation data and keep the final test set untouched.

Technical references: Google ML Crash Course: Overfitting scikit-learn: Common pitfalls and data leakage

Q007IntermediateConcept

What is the difference between L1 and L2 regularization?

Answer

L1 penalizes the sum of absolute weights and can produce sparse solutions. L2 penalizes squared weights and typically shrinks them smoothly. Regularization trades some training fit for generalization. Scale-sensitive models usually need sensible feature scaling before coefficient penalties are meaningfully comparable.

Technical references: scikit-learn: Logistic regression scikit-learn: Preprocessing

Q008IntermediateComparison

How do random forests and gradient boosting differ?

Answer

Random forests average randomized trees, typically trained using bootstrapped samples and feature subsampling. Gradient boosting adds models sequentially to improve an objective, often by fitting negative gradients. Forests are convenient robust baselines; boosting offers powerful tabular modeling but requires validation of depth, learning rate and iteration count.

Technical references: scikit-learn: Ensembles

Q009FoundationConcept

When should features be scaled?

Answer

Scaling matters for distance-based models, many linear models with regularization and gradient-based optimization. Standardization uses training-set mean and standard deviation. Tree models are usually much less sensitive to monotonic rescaling. A scaler must be fitted inside each training fold, not on the full dataset.

Technical references: scikit-learn: Preprocessing

Q010FoundationComparison

How do PCA and clustering differ?

Answer

PCA projects centered data onto orthogonal directions of high variance to reduce dimensionality. Clustering groups similar observations; k-means minimizes squared distances to cluster centers. PCA is not a clustering algorithm, and high-variance directions are not necessarily the most predictive or meaningful ones.

Technical references: scikit-learn: Matrix decomposition and PCA

Section 02 / 10

Data, statistics and evaluation

Q011FoundationConcept

Why separate training, validation and test data?

Answer

Training data fits parameters. Validation data supports model, threshold and hyperparameter decisions. Test data estimates final performance after choices are fixed. Cross-validation can improve use of limited data, but does not justify repeatedly inspecting and tuning against the final test set.

Technical references: scikit-learn: Model selection scikit-learn: Common pitfalls and data leakage

Q012FoundationDebugging

What is data leakage?

Answer

Leakage occurs when training or model selection uses information unavailable at prediction time, or information from held-out evaluation data. Examples include fitting preprocessing on all rows, future-derived features and duplicates across splits. Split first and fit transformations only within the training portion of each fold.

Technical references: scikit-learn: Common pitfalls and data leakage

Q013IntermediateScenario

How do you split grouped or time-dependent data?

Answer

Make the split resemble deployment. Keep related entities together when evaluating generalization to unseen entities, and train on the past when predicting the future. Use group-aware or time-aware validation; introduce a gap when label windows overlap. Random row splitting can otherwise produce misleadingly optimistic results.

Technical references: scikit-learn: Model selection scikit-learn: TimeSeriesSplit

Q014IntermediateScenario

How do you handle missing values and categorical features?

Answer

Investigate why data is missing before choosing imputation, an indicator or a model with native support. Encode categories in a way the estimator understands and define unknown-category behavior. Fit imputers and encoders on training folds only. Target encoding needs special care, typically out-of-fold training encodings.

Technical references: scikit-learn: Preprocessing scikit-learn: Common pitfalls and data leakage

Q015FoundationScenario

How do you handle class imbalance?

Answer

Choose metrics and thresholds based on error costs, not accuracy alone. Consider class weights, suitable resampling and additional data, but resample only within training folds. Preserve realistic evaluation prevalence and check calibration. A model predicting only the majority class can have high accuracy while being useless.

Technical references: scikit-learn: Model evaluation metrics

Q016FoundationCalculation

What are precision, recall and F1?

Answer

Precision = TP/(TP+FP), recall = TP/(TP+FN), and F1 = 2PR/(P+R). Precision focuses on the reliability of positive predictions; recall focuses on finding positives. F1 balances both but ignores true negatives and does not directly encode unequal business costs. Specify zero-denominator handling.

Worked example
A classifier has TP=40, FP=10 and FN=20. What are precision and recall?

Answer: Precision 0.80; recall about 0.667.

Precision is 40/50=0.80. Recall is 40/60, approximately 0.667. The denominators answer different questions.

Technical references: scikit-learn: Model evaluation metrics

Q017IntermediateComparison

When do you use ROC-AUC, PR curves and threshold-based metrics?

Answer

ROC-AUC measures ranking across true-positive and false-positive rates. Precision-recall analysis focuses on positive predictions and is often informative for rare positives. Average precision and trapezoidal PR-AUC are related but not identical. Evaluate the actual operating threshold, workload and error costs; AUC alone cannot choose them.

Technical references: scikit-learn: Model evaluation metrics

Q018FoundationCalculation

How do MAE and RMSE differ?

Answer

MAE averages absolute errors; RMSE is the square root of mean squared error. Both have the target variable's units, but RMSE penalizes large errors more heavily. Match the metric to the consequences of mistakes and inspect error slices rather than relying on a single aggregate.

Worked example
For prediction errors of 0 and 4, what are MAE and RMSE?

Answer: MAE=2; RMSE is approximately 2.828.

MAE=(0+4)/2=2. RMSE=sqrt((0 squared+4 squared)/2)=sqrt(8), approximately 2.828.

Technical references: scikit-learn: Model evaluation metrics

Q019IntermediateCalculation

What is Bayes' theorem and why do base rates matter?

Answer

Bayes' theorem is P(A|B)=P(B|A)P(A)/P(B), for P(B)>0. Posterior probabilities depend on both evidence and the prior rate. For rare events, even a low false-positive rate can produce many false alerts. Work through a count-based example instead of ignoring the denominator.

Practice aloud: Explain why deploying the same detector in a different-prevalence population can change precision.

Worked example
An event occurs in 1% of 10,000 cases. A detector has 90% recall and a 5% false-positive rate. Approximately what fraction of alerts are true?

Answer: 15.4%.

There are 90 true alerts and 495 false alerts. The true fraction is 90/(90+495), approximately 15.4%; recall is not alert precision.

Q020AdvancedExperiment

How do you design an A/B test and interpret significance?

Answer

Specify the randomization unit, primary metric, minimum useful effect, guardrails and analysis plan before the experiment. Check sample-ratio mismatch and uncertainty. A p-value is a tail probability under the null model, not the probability that the null is true. Statistical significance does not establish practical importance.

Technical references: NIST: Statistical tests

Section 03 / 10

Python, SQL and software engineering

Q021FoundationConcept

When do you use a list, tuple, set or dictionary in Python?

Answer

Use a list for an ordered mutable sequence, a tuple for a fixed collection of references, a set for unique hashable elements and membership checks, and a dictionary for key-value lookup. Tuples can contain mutable objects; immutability of the tuple does not make every nested object immutable.

Technical references: Python: Data structures

Q022FoundationCode reasoning

What is the mutable-default-argument bug?

Answer

Default arguments are evaluated when the function is defined, not on each call. A default list can therefore be shared across calls. Use None as the default and create a new list inside the function when no list is supplied. Do not confuse an intentionally shared cache with accidental state.

Worked example
What does this print?

def add_item(x, items=[]):
    items.append(x)
    return items

add_item(1)
print(add_item(2))

Answer: [1, 2]

Both calls use the same default list. The first call appends 1 and the second appends 2 to that existing object.

Technical references: Python: Default argument values

Q023IntermediateCode reasoning

How do assignment, shallow copy and deep copy differ?

Answer

Assignment creates another reference to the same object. A shallow copy creates a new outer container but retains references to nested objects. A deep copy recursively copies supported nested objects, subject to object-specific behavior. Copy only what is necessary, and test aliasing when nested mutable structures are involved.

Worked example
What does this print?

a = [[1], [2]]
b = a.copy()
b[0].append(9)
print(a[0])

Answer: [1, 9]

The outer list was copied, but a[0] and b[0] still refer to the same inner list.

Technical references: Python: Data structures

Q024FoundationConcept

Why use generators in data pipelines?

Answer

A generator yields values lazily, allowing incremental processing without storing the entire output collection. It is usually consumed once unless recreated. This helps with large files and batches, but does not by itself solve backpressure, parallelism or repeated access. Resources should be closed correctly when iteration ends early.

Practice aloud: Implement a batch iterator and test an empty input and a partial final batch.

Technical references: Python: Iterators and generators

Q025IntermediateCode reasoning

What is NumPy broadcasting?

Answer

Broadcasting lets compatible arrays participate in elementwise operations without explicitly copying repeated data. Compare shapes from the trailing dimension: sizes must match or one must be 1. The output can still be large, so inspect shapes and memory use. Broadcasting is different from matrix multiplication.

Worked example
If a has shape (3, 1) and b has shape (1, 4), what is the shape of a + b?

Answer: (3, 4)

The trailing dimensions 1 and 4 expand to 4; the leading dimensions 3 and 1 expand to 3.

Technical references: NumPy: Broadcasting

Q026IntermediateAlgorithm

How would you find the top k scores in a large stream?

Answer

Maintain a min-heap of at most k items. For each new item, keep it if the heap is not full or it exceeds the minimum. For n items and k>=2, this takes O(n log k) time and O(k) additional memory; k=1 reduces to a linear maximum scan.

Practice aloud: State how ties, k=0, k>n and non-finite scores should be handled.

Technical references: Python: heapq

Q027IntermediateComparison

When should an AI service use async I/O, threads or processes?

Answer

Async I/O overlaps waiting for network or disk operations when libraries cooperate with the event loop. It does not automatically parallelize CPU-heavy Python work. CPU-bound work may need processes, native implementations or accelerators. Thread behavior depends on the Python runtime and whether native code releases the GIL.

Technical references: Python: asyncio

Q028IntermediateTesting

What tests should an AI application have?

Answer

Use unit tests for deterministic logic, integration tests for component contracts, and end-to-end tests for user workflows. Separately evaluate model quality on representative cases and regressions. Test invalid input, authorization failures, unavailable dependencies and timeouts. A passing software test suite does not prove the model is accurate.

Technical references: Google: Rules of Machine Learning OpenAI: Evaluation best practices

Q029IntermediateSQL

How do you retrieve the latest row per user in SQL?

Answer

Use ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY event_time DESC, event_id DESC) in a CTE or subquery, then filter rn=1. A deterministic tie-breaker matters. Define null-time handling for your database. GROUP BY user_id with MAX(event_time) alone does not return all columns from the matching row.

Worked example
Which pattern returns one latest event row per user with a deterministic tie-breaker?

Answer: ROW_NUMBER over user_id ordered by event_time DESC and event_id DESC, then keep row 1.

A window ranking selects a row inside each user partition. A global limit would return one row overall, not one per user.

Technical references: PostgreSQL: Window functions

Q030IntermediateCode reasoning

How do you implement a numerically stable softmax?

Answer

For finite logits, subtract the maximum before exponentiating: p_i=exp(z_i-max(z))/sum_j exp(z_j-max(z)). The shift preserves probabilities while preventing overflow from large positive logits. Define the input axis, reject invalid or empty inputs as appropriate, and test normalization and extreme values.

Practice aloud: The probabilities are approximately [0.269, 0.731]; explain why the larger logit gets more mass.

Worked example
Which computation is preferable for softmax([1000, 1001])?

Answer: Subtract 1001, exponentiate [-1, 0], then normalize.

Adding or subtracting a common constant does not change softmax. The shifted exponents are bounded above by 1, avoiding positive-exponent overflow.

Section 04 / 10

Deep learning and training

Q031FoundationConcept

Why do neural networks need nonlinear activations?

Answer

A stack of linear layers without nonlinearities is still a linear transformation. Activations such as ReLU or GELU let a network represent nonlinear relationships. Choose output activations and losses together: multiclass classification often uses logits with cross-entropy, while regression may use an unconstrained numeric output.

Technical references: Google ML Crash Course: Backpropagation

Q032FoundationCalculation

What are backpropagation and automatic differentiation?

Answer

Backpropagation applies the chain rule to compute gradients through a computation graph. Automatic differentiation tracks operations and evaluates these derivatives; it is not the same as finite-difference approximation. Gradients indicate local sensitivity of the loss to parameters, and an optimizer uses them to update parameters.

Worked example
For y=w*x and loss L=(y-t)^2, what is dL/dw when x=3, w=2 and t=4?

Answer: 12.

y=6, so dL/dw=2*(6-4)*3=12. The input multiplier comes from differentiating y with respect to w.

Technical references: Google ML Crash Course: Backpropagation PyTorch: Autograd mechanics

Q033IntermediateDiagnosis

How do learning rate, SGD and Adam affect training?

Answer

The learning rate controls update size. Too large can destabilize training; too small can make learning slow. SGD follows gradients, often with momentum; Adam adapts updates using moving averages of gradients and squared gradients. Choose optimizer, scheduling and weight decay through controlled validation rather than assuming one is universally best.

Technical references: Google ML Crash Course: Backpropagation

Q034FoundationCalculation

What are epochs, batches and optimizer steps?

Answer

An epoch is one pass through the training dataset. A mini-batch is a subset processed together. An optimizer step updates parameters; gradient accumulation can combine multiple mini-batches before one update. Specify drop-last behavior, distributed sampling and accumulation when calculating the number of steps.

Worked example
There are 1,000 examples, batch size 100, no accumulation and no dropped rows. How many optimizer steps are in 3 epochs?

Answer: 30.

Each epoch has 1,000/100=10 batches and one update per batch. Three epochs therefore require 30 optimizer steps.

Q035IntermediateComparison

How do dropout, batch normalization and layer normalization differ?

Answer

Dropout randomly suppresses activations during training as regularization. Batch normalization uses statistics over batch-related dimensions and commonly uses running statistics at inference. Layer normalization normalizes within an example over specified features. They serve different purposes and their train/evaluation behavior must be handled correctly.

Technical references: PyTorch: Autograd mechanics PyTorch: LayerNorm PyTorch: BatchNorm1d

Q036IntermediateCode reasoning

What is the difference between model.eval() and no_grad()?

Answer

model.eval() changes the behavior of modules such as dropout and batch normalization. torch.no_grad() disables recording operations for gradient calculation in its scope. They are not interchangeable. For inference, typically use evaluation mode with no_grad() or inference_mode(), while respecting the latter's additional tensor restrictions.

Worked example
Which statement is true in PyTorch?

Answer: model.eval() does not, by itself, disable autograd recording.

Evaluation mode controls layer behavior; gradient modes control autograd. Ordinary inference commonly needs both.

Technical references: PyTorch: Autograd mechanics

Q037IntermediateDiagnosis

What causes vanishing or exploding gradients?

Answer

Repeated transformations can shrink or amplify gradients, especially in deep or recurrent networks. Inspect gradient norms and activation statistics. Appropriate initialization, normalization, residual connections and architecture choices can help; gradient clipping limits large gradients. Clipping does not repair every optimization or data problem.

Technical references: Google ML Crash Course: Backpropagation

Q038IntermediateConcept

How do you choose a neural-network loss?

Answer

Match the statistical task: multiclass cross-entropy for one class among alternatives, binary cross-entropy for binary or independent multilabel targets, and a suitable regression loss for numeric targets. Understand whether a library expects logits or probabilities. Loss functions and business evaluation metrics are not necessarily identical.

Practice aloud: Explain how binary, multiclass and multilabel targets change output shape and loss choice.

Technical references: PyTorch: CrossEntropyLoss

Q039FoundationScenario

What is transfer learning and how would you fine-tune a pretrained model?

Answer

Transfer learning reuses representations learned on another task or dataset. Start with a pretrained backbone and train a task head, or unfreeze selected layers using an appropriate learning rate. Check domain mismatch, preprocessing requirements, licenses and independent evaluation. Freezing layers reduces trainable parameters but does not eliminate inference cost.

Practice aloud: Discuss domain shift, augmentation validity and the risk of overfitting a small dataset.

Q040AdvancedDiagnosis

How do you debug GPU out-of-memory errors?

Answer

Identify whether weights, optimizer states, activations or inference KV cache dominate memory. Depending on the cause, reduce micro-batch size or sequence length, use mixed precision, checkpoint activations, accumulate gradients or shard the model. Gradient accumulation lowers per-step activation memory, but does not shrink the model's weights.

Practice aloud: Explain which memory component activation checkpointing trades for extra computation.

Technical references: PyTorch: Automatic mixed precision and accumulation

Section 05 / 10

LLMs and transformers

Q041FoundationConcept

What are tokens and embeddings?

Answer

Tokens are model-specific units such as subwords or bytes; they are not necessarily whole words. Embeddings map tokens, passages or other objects into numeric vectors. Similarity depends on the embedding model and training objective. A vector's closeness is not proof of factual agreement or permission to reveal its source.

Technical references: Vaswani et al.: Attention Is All You Need Hugging Face: Generation configuration

Q042IntermediateCalculation

How does scaled dot-product attention work?

Answer

Queries and keys produce relevance scores, and those scores weight value vectors: Attention(Q,K,V)=softmax(QK^T/sqrt(d_k))V. Masks restrict permitted interactions. For a sequence of n tokens, ordinary dense self-attention has an n-by-n score structure per head; implementation memory and efficiency depend on the attention algorithm.

Worked example
If Q and K each have shape (n, d_k), what is the shape of QK^T?

Answer: (n, n).

Multiplying an n-by-d_k matrix by a d_k-by-n matrix produces n-by-n pairwise attention scores.

Technical references: Vaswani et al.: Attention Is All You Need

Q043IntermediateConcept

Why use multiple attention heads and positional information?

Answer

Multiple heads learn different projections and attention patterns rather than sharing one representation. Positional mechanisms provide order information that plain attention alone does not encode in the same way as recurrence. Implementations may use learned, sinusoidal or relative-position approaches; the exact mechanism is architecture-dependent.

Technical references: Vaswani et al.: Attention Is All You Need

Q044IntermediateComparison

How do encoder-only, decoder-only and encoder-decoder models differ?

Answer

Encoder-only models commonly build bidirectional representations. Decoder-only language models commonly generate autoregressively with causal masking. Encoder-decoder models encode an input and generate an output while attending to it. Choose according to representation, generation and sequence-to-sequence needs, not simply parameter count.

Technical references: Vaswani et al.: Attention Is All You Need

Q045IntermediateComparison

How do pretraining, supervised fine-tuning, RLHF and DPO differ?

Answer

Pretraining learns broad representations or generative structure from large datasets. Supervised fine-tuning trains on desired input-output examples. RLHF commonly uses human preferences to construct a reward signal and optimize behavior. DPO directly optimizes a preference-based objective relative to a reference policy without requiring that separate RL training loop.

Technical references: Rafailov et al.: Direct Preference Optimization

Q046FoundationConcept

What do temperature, top-k and top-p control?

Answer

These settings affect token selection in supported sampling implementations. Temperature rescales logits; top-k restricts candidate count; top-p retains a high-probability nucleus. Lower randomness can improve repeatability but does not guarantee truth or exact reproducibility. Some models and endpoints expose different controls, so inspect their actual API.

Technical references: Hugging Face: Generation configuration

Q047IntermediateCalculation

How do you budget a context window?

Answer

Account for instructions, conversation history, retrieved passages, tool messages and reserved output tokens. Respect both the model's total context limit and any separate output limit. Truncation, summarization and retrieval require evaluation because they can remove important evidence. Larger context does not guarantee that all included facts are used correctly.

Worked example
A hypothetical model allows 8,192 combined input and output tokens. The input uses 6,500. What is the maximum output budget before other constraints?

Answer: 1,692 tokens.

8,192 minus 6,500 equals 1,692. This is a hypothetical arithmetic example, not the specification of a particular model.

Technical references: Hugging Face: Generation configuration

Q048FoundationScenario

What are hallucinations and how can you reduce them?

Answer

A hallucination is generated content that is unsupported or incorrect for the task. Reduce risk using reliable retrieval, verified tools, clear evidence requirements, explicit abstention paths and evaluation on difficult cases. Citations can also be wrong; verify that the cited source actually supports the associated claim.

Technical references: Lewis et al.: Retrieval-Augmented Generation OpenAI: Evaluation best practices

Q049AdvancedComparison

What are LoRA and QLoRA?

Answer

LoRA trains low-rank weight updates while freezing the base weights, reducing trainable parameters and optimizer-state requirements. QLoRA combines adapter training with a quantized frozen base model, commonly using 4-bit base weights. This does not mean all computation or trainable adapters are 4-bit; validate quality, compatibility and memory use.

Technical references: Hugging Face PEFT: Quantization and QLoRA

Q050IntermediateComparison

How do quantization, pruning and distillation differ?

Answer

Quantization uses lower-precision representations; pruning removes or suppresses parameters or structures; distillation trains a student from a teacher's outputs or representations. They can trade quality for cost or memory differently. Reduced model size does not automatically produce faster inference on every hardware and kernel combination.

Technical references: Hugging Face PEFT: Quantization and QLoRA

Section 06 / 10

RAG and information retrieval

Q051FoundationArchitecture

What is retrieval-augmented generation?

Answer

RAG retrieves external information and conditions generation on that evidence. A practical pipeline ingests and versions documents, parses and chunks them, indexes representations, retrieves authorized candidates, optionally reranks, and generates an answer with supporting references. Evaluate retrieval and generation separately; RAG does not guarantee factuality.

Technical references: Lewis et al.: Retrieval-Augmented Generation

Q052IntermediateDecision

When should you use prompting, RAG or fine-tuning?

Answer

Use prompting for task instructions and examples; use RAG when answers need external, private, changing or attributable knowledge; consider fine-tuning for persistent behavioral or task-performance gaps supported by training data. The methods can be combined. Diagnose the failure before selecting a technique and compare against a simpler baseline.

Technical references: Lewis et al.: Retrieval-Augmented Generation Hugging Face PEFT: Quantization and QLoRA

Q053IntermediateTrade-off

How do you choose chunk size and overlap?

Answer

Preserve useful semantic units, headings, provenance and table relationships. Small chunks can lose context; large chunks can dilute retrieval or consume the context budget. Overlap can reduce boundary loss but increases duplication and storage. Choose settings using real retrieval and answer-quality tests, not a universal fixed chunk size.

Technical references: Sentence Transformers: Retrieve and re-rank

Q054IntermediateCalculation

How do cosine similarity and dot product differ?

Answer

Cosine similarity is the dot product divided by the vectors' norms; it compares direction for nonzero vectors. Dot product also depends on magnitude. They coincide for unit-normalized vectors. Use the metric expected by the embedding model and explicitly handle zero vectors rather than silently dividing by zero.

Practice aloud: Explain why mixing unnormalized dot-product scores with cosine scores can change rankings.

Worked example
What is the cosine similarity between [1, 0] and [1, 1]?

Answer: 1/sqrt(2), approximately 0.707.

The dot product is 1; the norms are 1 and sqrt(2), giving 1/sqrt(2).

Q055AdvancedTrade-off

What is approximate nearest-neighbor search?

Answer

ANN methods trade exact nearest-neighbor guarantees for practical speed and scale. Tune search effort, memory and index construction against recall and latency. Compare results against an exact baseline on a representative sample. ANN recall against exact neighbors is not the same as semantic relevance to the user's task.

Practice aloud: Discuss how access filters and changes in corpus size can affect retrieval performance.

Q056IntermediateComparison

What are sparse, dense and hybrid retrieval?

Answer

Sparse lexical methods such as BM25 use term-based signals; dense methods use learned vectors. Lexical matching can help with exact identifiers, while dense search can capture semantic relationships. Hybrid retrieval combines candidate sets or rankings, for example with reciprocal rank fusion, and should be tested on representative queries.

Technical references: Elastic: Reciprocal rank fusion

Q057IntermediateArchitecture

What does a reranker do?

Answer

A reranker scores a smaller candidate set more carefully after initial retrieval. A cross-encoder can jointly process the query and candidate text, trading additional computation for richer interactions. Reranking cannot recover a relevant document that was never retrieved unless another retrieval stage supplies it.

Technical references: Sentence Transformers: Retrieve and re-rank

Q058IntermediateCalculation

How do you evaluate retrieval quality?

Answer

Use labeled relevant documents or passages. Recall@k measures the fraction of relevant items retrieved; MRR emphasizes the rank of the first relevant result; nDCG supports graded relevance and rank position. State the relevance unit and labeling coverage. Also evaluate whether the retrieved evidence is sufficient for the actual answer.

Practice aloud: Do not confuse retrieval Recall@k with ANN recall relative to exact nearest neighbors.

Worked example
A query has 4 labeled relevant documents. The top 5 results contain 3 of them. What is Recall@5?

Answer: 0.75.

Recall@5=3/4=0.75. Three relevant items out of five retrieved would instead give Precision@5=0.60.

Technical references: scikit-learn: Model evaluation metrics

Q059AdvancedDiagnosis

How do you debug a RAG answer that is wrong?

Answer

Inspect the stages: source coverage, parsing, chunking, authorization filters, retrieval, reranking, context assembly and generation. Check whether the necessary evidence reached the model. Test generation with known-good evidence to separate retrieval failure from answer-generation failure. Also verify source freshness and citation alignment.

Technical references: Lewis et al.: Retrieval-Augmented Generation OpenAI: Evaluation best practices

Q060AdvancedArchitecture

How do you maintain an evolving retrieval index?

Answer

Track document IDs, versions, permissions and deletion state; propagate updates and invalidate stale caches. Query and document embeddings must belong to a compatible embedding space. When changing models, plan a versioned migration and re-embedding of the corpus, even when vector dimensions happen to match.

Q061FoundationPractice

What makes a useful prompt?

Answer

State the task, relevant context, constraints, output expectations and examples when helpful. Separate trusted instructions from quoted or retrieved material. Specify what to do when evidence is missing. Keep the prompt understandable and evaluate it against realistic cases; extra length and emphatic wording do not ensure better behavior.

Technical references: OpenAI: Structured model outputs OpenAI: Evaluation best practices

Q062IntermediatePractice

When do few-shot examples help, and how should you request reasoning?

Answer

Few-shot examples can clarify a desired format or decision boundary without changing model weights. Use representative examples and include difficult cases rather than leaking test answers. Ask for concise justifications or verifiable intermediate outputs where useful. Long explanations are not evidence of correctness; evaluate the answer and its support.

Technical references: OpenAI: Evaluation best practices

Q063IntermediateScenario

Do structured outputs guarantee correct data?

Answer

Schema-constrained output can improve structural reliability, but a valid schema does not prove values are true, authorized or internally consistent. Validate semantic constraints in application code and handle refusals, incomplete responses and unsupported schema features. Treat model output as untrusted input to downstream systems.

Technical references: OpenAI: Structured model outputs OWASP: Improper output handling

Q064IntermediateArchitecture

How does tool or function calling work?

Answer

The model proposes a tool name and arguments using the provided interface. Application code validates the proposal, checks authorization, executes the allowed operation and returns the result to the model. Model-generated arguments are not authorization. Handle failures, duplicate requests and tool results that contain untrusted text.

Technical references: OpenAI: Function calling OWASP: Excessive agency

Q065IntermediateComparison

What distinguishes an agent from a fixed workflow?

Answer

A fixed workflow follows an explicitly designed sequence or routing logic. An agent gives the model more responsibility for selecting steps or tools based on intermediate results. More autonomy adds flexibility but also failure modes. Prefer a deterministic workflow when it meets the requirement with lower cost and easier testing.

Technical references: OWASP: Excessive agency OpenAI: Evaluation best practices

Q066AdvancedReliability

How do you keep an agent from looping or overspending?

Answer

Set explicit limits on steps, time, tokens, tool calls and money. Detect repeated states or actions, define success criteria and provide a safe fallback. Make side-effecting operations idempotent where possible. Track traces so that an apparent success can be audited against actual tool outcomes.

Technical references: OWASP: Excessive agency

Q067IntermediateComparison

How do conversation history, long-term memory and KV cache differ?

Answer

Conversation history is prior interaction content supplied to the model. Long-term memory is application-managed stored information retrieved across interactions. KV cache stores attention-related tensors to avoid recomputing earlier tokens. A KV cache is not a database of verified user facts, and memory needs access controls, retention rules and correction paths.

Technical references: Hugging Face: KV cache strategies

Q068IntermediateEvaluation

How should an LLM application be evaluated?

Answer

Define a task-specific rubric and representative evaluation set containing normal, edge and adversarial cases. Use deterministic checks where possible, expert review where needed and calibrated model-based graders where useful. Track quality, safety, latency and cost. Version the evaluation and run it when prompts, models, tools or data change.

Technical references: OpenAI: Evaluation best practices

Q069AdvancedEvaluation

What are the limitations of LLM-as-a-judge?

Answer

A model judge can be scalable but may show position, verbosity, style or self-preference biases and miss factual errors. Calibrate against expert labels, specify a rubric and investigate disagreements. For pairwise judgments, vary answer order. Protect the evaluator from instructions embedded in the content it grades.

Technical references: OpenAI: Evaluation best practices

Q070AdvancedEvaluation

How do you avoid overfitting an LLM evaluation?

Answer

Separate prompt-development cases from held-out tests. Avoid inserting test answers into prompts, fine-tuning data or curated retrieval shortcuts. Add fresh and adversarial cases, track provenance and repeat variable tests appropriately. A rising benchmark score can reflect memorization or evaluation contamination rather than broader task improvement.

MLOps, deployment and system design

Q071IntermediateMLOps

What should be versioned for reproducible AI experiments?

Answer

Record code, data snapshots or manifests, preprocessing, labels, configuration, dependencies, model artifacts, prompts and evaluation definitions. Record seeds, hardware and relevant runtime settings as well. Seeds alone do not guarantee identical results across hardware or software versions. Preserve enough provenance to explain and reproduce an important result.

Technical references: Google Cloud: MLOps pipelines

Q072IntermediateDiagnosis

What is training-serving skew?

Answer

Training-serving skew occurs when data or processing differs between training and production. Causes include inconsistent feature transformations, unavailable future information, stale lookups and different defaults. Reuse transformation logic, test parity and use point-in-time-correct feature joins. Compare actual serving inputs with the assumptions made during training.

Technical references: Google: Rules of Machine Learning

Q073IntermediateComparison

How do data drift and concept drift differ?

Answer

Data drift changes the input distribution P(X); concept drift changes the relationship P(Y|X). Label distribution can change too. Monitor schema, inputs, predictions and observed outcomes by slice. A drift alert is a reason to investigate, not proof that quality has fallen or that automatic retraining is safe.

Technical references: Google Cloud: MLOps pipelines

Q074IntermediateArchitecture

When do you choose batch, online or streaming inference?

Answer

Batch inference processes collections when immediate responses are unnecessary. Online inference serves requests under latency constraints. Streaming inference continuously processes incoming events, often with state and ordering concerns. Choose from freshness, throughput, cost and failure requirements; model training mode is independent of this serving choice.

Technical references: Google: Rules of Machine Learning Google Cloud: MLOps pipelines

Q075AdvancedDeployment

How do canary, shadow and rollback strategies work?

Answer

A canary routes a controlled portion of real traffic to a new version. Shadowing runs a candidate on mirrored inputs without using its output for the user decision. Rollback restores a known-good version. Define guardrails, compatible artifacts, observability and rollback triggers before rollout; prevent side effects from shadow execution.

Technical references: Google Cloud: MLOps pipelines

Q076AdvancedAPI design

What makes an AI API production-ready?

Answer

Use input validation, authentication, authorization, resource limits, timeouts, observability and clear error contracts. Apply bounded retries with backoff and jitter for suitable transient failures. Use idempotency or equivalent deduplication for side-effecting operations. Handle streaming cancellation and avoid exposing API keys in client-side code.

Technical references: Google SRE: Monitoring distributed systems OWASP: Excessive agency

Q077IntermediateCalculation

Which latency and cost metrics matter for LLM serving?

Answer

Track time to first token, end-to-end latency, output rate, throughput, error rate and tail percentiles such as p95. Measure tokens and tool or infrastructure costs per successful task. Streaming can improve perceived responsiveness without reducing total compute. Compare quality, cost and latency together rather than optimizing a single proxy.

Worked example
In a hypothetical pricing model, input costs $2 per million tokens and output costs $8 per million. What is the token cost of 1,000 input and 250 output tokens?

Answer: $0.004, excluding other charges.

Input costs 1,000/1,000,000*2=$0.002. Output costs 250/1,000,000*8=$0.002. Total=$0.004. These are invented rates for arithmetic practice.

Q078AdvancedPerformance

What does a KV cache save, and what does it cost?

Answer

Autoregressive generation can reuse keys and values computed for earlier tokens instead of recomputing them at every step. The cache consumes memory that grows with active sequences and retained context for full-attention layers. Cache strategies can trade memory for speed. KV caching is distinct from caching a completed response.

Technical references: Hugging Face: KV cache strategies

Q079AdvancedArchitecture

How would you improve large-model inference throughput?

Answer

Profile the bottleneck before changing the system. Test batching or continuous batching, shorter contexts, quantization, better kernels, appropriate parallelism and model routing. Evaluate queueing and tail latency alongside throughput. An optimization that increases total tokens per second may worsen an individual user's response time.

Technical references: Google SRE: Monitoring distributed systems Hugging Face: KV cache strategies

How would you design a production document-support assistant?

Answer

Clarify users, permissions, corpus size, freshness, accuracy targets, latency and budget. Separate document ingestion and versioned indexing from online retrieval and answer generation. Enforce access before evidence reaches the model; add citations, abstention and escalation. Define evaluation, monitoring, caches, failure handling and safe rollout before choosing vendors.

Security, responsible AI and decisions

Q081IntermediateSecurity

What is prompt injection?

Answer

Prompt injection occurs when untrusted input attempts to redirect model behavior against the application's intended instructions. It can be direct user input or indirect content in documents and tool results. Prompts are not a security boundary: combine isolation, restricted tools, authorization, validation and monitoring to reduce consequences.

Technical references: OWASP: Prompt injection

Q082AdvancedSecurity

How do you apply least privilege to AI agents?

Answer

Expose only the tools and permissions needed for the task. Enforce per-user authorization in trusted code, scope credentials, sandbox risky execution and constrain network or filesystem access. Require approval for consequential actions where appropriate. A model's stated intention is not a substitute for enforced permissions.

Technical references: OWASP: Excessive agency

Q083AdvancedSecurity

How do you prevent cross-tenant data leakage in RAG?

Answer

Derive tenant and user identity from trusted authentication, enforce document permissions before content reaches the model, and scope storage, retrieval and caches appropriately. Recheck permissions on tool actions. Test cross-tenant identifiers, stale permissions and cache collisions. Do not rely on the prompt to hide unauthorized context.

Technical references: OWASP: Excessive agency OWASP: Prompt injection

Q084IntermediatePrivacy

How should an AI system handle sensitive information?

Answer

Minimize what is collected, sent and retained; use access controls and appropriate encryption. Redact secrets from logs and inspect provider data-handling terms for the deployment. Treat prompts, traces, embeddings and caches as potentially sensitive. Define deletion, retention and incident procedures with the relevant privacy and security teams.

Q085IntermediateSecurity

Why must model-generated output be validated before use?

Answer

Generated SQL, HTML, URLs and code can contain mistakes or attacker-influenced content. Apply schema and semantic checks, context-appropriate escaping, query parameterization and restricted execution. Do not pass untrusted output directly to eval, a shell or a privileged database. Validation must match the downstream use, not just whether the text parses.

Q086AdvancedSecurity

What are AI supply-chain risks?

Dependencies, model artifacts, datasets and remote loading code can be compromised or unsuitable. How do you evaluate fairness?

Answer

Measure relevant performance and error rates across meaningful groups, including intersections when sample sizes permit. Check representation, label quality and the impact of decisions. Fairness criteria can conflict, so select them with domain stakeholders and document trade-offs. Removing a sensitive column does not remove proxies or guarantee fair outcomes.

Q088IntermediateResponsible AI

What do feature importance and explanations tell you?

Answer

Importance methods describe how predictions or model behavior relate to inputs under particular assumptions. They are not automatically causal explanations. Correlated features, background data and distribution shifts can affect results. What are calibration and uncertainty-aware fallback?

Q091IntermediateSpecialist calculation

How do classification, detection and segmentation differ in computer vision?

Answer

Classification assigns labels to an image or region. Detection predicts objects and their locations, often as boxes. Segmentation assigns pixel-level labels or instance masks. Intersection over union is intersection area divided by union area. Detection evaluation also depends on confidence ranking, class matching and localization thresholds.

Worked example
Two predicted/reference boxes have intersection area 20 and union area 50. What is their IoU?

Answer: 0.40.

IoU=20/50=0.40. It measures overlap relative to the combined covered area, not just the area of either box.

Technical references: Torchvision: Intersection over union

Q092IntermediateSpecialist concept

How do diffusion and autoregressive generation differ?

Answer

Autoregressive generation produces components conditionally in sequence, such as one token after another. Diffusion models learn to reverse a corruption process and generate through denoising steps, often in a latent space. Their training objectives and sampling trade-offs differ. Neither family guarantees factual, safe or bias-free content.

Technical references: Ho et al.: Denoising Diffusion Probabilistic Models

Q093IntermediateSpecialist calculation

What is word error rate in speech recognition?

Answer

WER=(substitutions+deletions+insertions)/number of reference words. Lower is better, but text normalization, language and task context matter. WER can exceed 100% when insertions are numerous. Also inspect important entities, noise conditions, accents, streaming latency and other failures relevant to actual use.

Worked example
An ASR output has 2 substitutions, 1 deletion and 1 insertion against 20 reference words. What is WER?

Answer: 20%.

WER=(2+1+1)/20=4/20=0.20. The denominator is the reference word count.

Technical references: Hugging Face Audio Course: ASR evaluation

New users or items have little interaction history. Use content features, context, onboarding preferences or appropriate popularity baselines while collecting feedback responsibly. A common system separates candidate generation from ranking. Evaluate offline relevance and online outcomes without leaking future interactions or reinforcing feedback loops blindly.

A policy chooses actions from observations or states. A reward provides feedback; a value function estimates expected future return under specified conditions. An MDP formalizes states, actions, transitions and rewards. Exploration trades immediate performance for information, and reward design must avoid optimizing a proxy that defeats the real goal.

1. Stable softmax
def stable_softmax(logits: Sequence[float]) -> list[float]:
    """Return softmax for a nonempty, finite, one-dimensional input.

    Time: O(n). Additional space: O(n).
    Subtracting the maximum prevents overflow of positive exponents.
    """
    values = [float(x) for x in logits]
    if not values or not all(math.isfinite(x) for x in values):
        raise ValueError('logits must be nonempty and finite')
    maximum = max(values)
    weights = [math.exp(x - maximum) for x in values]
    total = math.fsum(weights)
    return [weight / total for weight in weights]

Test and discuss: Test [1000, 1001], a single value, empty input, NaN and shift invariance. Explain why subtracting the maximum does not change the result.

2. Cosine similarity
def cosine_similarity(a: Sequence[float], b: Sequence[float]) -> float:
    """Cosine of two finite, equal-length, nonzero vectors.

    Scale each vector first to reduce overflow risk in norm calculations.
    Zero vectors are rejected because their cosine is undefined.
    Time and additional space: O(d).
    """
    x, y = [float(v) for v in a], [float(v) for v in b]
    if not x or len(x) != len(y):
        raise ValueError('vectors must be nonempty and have equal lengths')
    if not all(math.isfinite(v) for v in x + y):
        raise ValueError('vectors must contain only finite values')
    sx, sy = max(map(abs, x)), max(map(abs, y))
    if sx == 0 or sy == 0:
        raise ValueError('cosine is undefined for a zero vector')
    x, y = [v / sx for v in x], [v / sy for v in y]
    nx = math.sqrt(math.fsum(v * v for v in x))
    ny = math.sqrt(math.fsum(v * v for v in y))
    result = math.fsum(u * v for u, v in zip(x, y)) / (nx * ny)
    return max(-1.0, min(1.0, result))

Test and discuss: Test orthogonal, identical and opposite vectors, mismatched lengths, zeros and very large values. Explain the explicit zero-vector policy.

3. Streaming top-k
def top_k_scores(scores: Iterable[float], k: int) -> list[float]:
    """Return the largest k finite scores, sorted descending, retaining ties.

    k=0 returns [] without consuming scores. k>n returns all n scores.
    For k>=2: O(n log k + k log k) time, O(k) auxiliary space.
    For k=1: O(n) time. Reject negative or noninteger k.
    """
    if isinstance(k, bool) or not isinstance(k, int) or k < 0:
        raise ValueError('k must be a nonnegative integer')
    if k == 0:
        return []
    heap: list[float] = []
    for raw in scores:
        value = float(raw)
        if not math.isfinite(value):
            raise ValueError('scores must be finite')
        if len(heap) < k:
            heapq.heappush(heap, value)
        elif value > heap[0]:
            heapq.heapreplace(heap, value)
    return sorted(heap, reverse=True)

Test and discuss: Test ties, negatives, k=0, k=1, k greater than the input length, empty input and NaN. Distinguish heap maintenance from sorting the final output.

4. Memory-bounded batching
def batches(items: Iterable[T], size: int) -> Iterator[list[T]]:
    """Yield bounded lists; keep the partial final batch.

    Time: O(n), working memory: O(size), excluding batches kept by the caller.
    Because this is a generator, argument validation runs at first iteration.
    """
    if isinstance(size, bool) or not isinstance(size, int) or size <= 0:
        raise ValueError('size must be a positive integer')
    batch: list[T] = []
    for item in items:
        batch.append(item)
        if len(batch) == size:
            yield batch
            batch = []
    if batch:
        yield batch

Test and discuss: Test empty input, an exact multiple of the batch size, a partial final batch and an invalid size. The caller must avoid retaining every batch when memory is limited.

5. Latest row per user in SQL
-- Worked exercise 5: PostgreSQL, latest non-null-timestamp event per user.
-- event_id is assumed unique. DESC on event_id breaks timestamp ties.
-- Keep null timestamps excluded here; choose a different explicit policy if needed.
WITH ranked_events AS (
    SELECT
        user_id,
        event_id,
        event_time,
        payload,
        ROW_NUMBER() OVER (
            PARTITION BY user_id
            ORDER BY event_time DESC, event_id DESC
        ) AS rn
    FROM events
    WHERE event_time IS NOT NULL
)
SELECT user_id, event_id, event_time, payload
FROM ranked_events
WHERE rn = 1;

-- Why MAX(event_time) alone is insufficient:
-- It finds the timestamp, but does not identify all other values from its row.
-- Joining back on the timestamp can still return multiple rows when times tie.

Test and discuss: State tie and null policies. Test multiple users, equal timestamps, a user with only null timestamps and an empty table.

6. Leakage-safe ML baseline
"""Worked exercise 6: a leakage-safe binary-classification baseline.
Requires numpy and scikit-learn. No network or external data is used.
Install in your own virtual environment when necessary:
    python -m pip install numpy scikit-learn
Run:
    python leakage_safe_pipeline.py
"""
from sklearn.datasets import make_classification
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, average_precision_score
from sklearn.model_selection import StratifiedKFold, cross_val_score, train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler


def main() -> None:
    X, y = make_classification(
        n_samples=1500, n_features=12, n_informative=7,
        weights=[0.8, 0.2], random_state=42,
    )
    X_train, X_test, y_train, y_test = train_test_split(
        X, y, test_size=0.2, stratify=y, random_state=42,
    )
    model = make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000))
    cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
    # Each fold fits its own scaler only on its training rows.
    scores = cross_val_score(model, X_train, y_train, cv=cv, scoring='average_precision')
    print(f'Training-fold CV average precision: {scores.mean():.3f} +/- {scores.std():.3f}')
    # Configuration is now fixed; test data has not been used for selection.
    model.fit(X_train, y_train)
    probabilities = model.predict_proba(X_test)[:, 1]
    print(f'Held-out average precision: {average_precision_score(y_test, probabilities):.3f}')
    print(f'Held-out accuracy at default threshold: {accuracy_score(y_test, model.predict(X_test)):.3f}')
    # Do not revise the pipeline using this final test score and call it untouched.
    # Real grouped or temporal data may need a different splitter.


if __name__ == '__main__':
    main()

Test and discuss: The example uses synthetic independent rows. For grouped or temporal data, change the split to match deployment. Do not repeatedly tune on the final test results.
