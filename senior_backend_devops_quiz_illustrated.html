Before you start

The quiz runs locally without a server or network connection. Progress is saved in this browser when local storage is permitted; private mode, file restrictions or clearing browser data may remove it. Use one quiz tab at a time. The bank is bundled in the HTML, so this is a self-study tool, not a secure or proctored examination. Scores are not a validated hiring benchmark.

Technology-specific examples use PostgreSQL, Linux, Docker, Kubernetes, Terraform, GitHub Actions, Python, Node.js and Java. No claim is made that these are statistically the most frequently asked employer questions.
